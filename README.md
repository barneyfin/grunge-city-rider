# Grunge City Rider (beta)

**Play it: https://barneyfin.github.io/grunge-city-rider/**

You drive a night-shift taxi up Nathan Road in the rain. Pick up a passenger at the teal bay, drop them at the pink bay further on, and the meter counts the fare. Five fares clear a district. The clock runs down all the while and each fare buys time back. The run ends when the time runs out or on the third crash.

This is a test version, so things may change or go wrong. It runs in your web browser with nothing to install, on a phone or a computer. The page is about 11 MB, because the music is inside it, so on a phone you may want Wi-Fi the first time.

## Controls

| | Phone or tablet | Keyboard |
|---|---|---|
| Steer | Drag on the left of the taxi | ← → (or A, D) |
| Brake | Hold on the right of the taxi | ↓ (or S) |
| Horn | A quick tap on either side | Space |
| Pause | The pause button | Esc |

## What's here

- `index.html` is the whole game in one file, built from the City Nights kit.
- `licences/` holds the SIL Open Font Licences for the fonts inside the game.
